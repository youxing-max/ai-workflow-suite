# 审查契约 · <module>

> 一个模块一份，存 `docs/ai-workflow/review-contracts/<module>.md`；全仓库共用的规则写仓库根 `REVIEW.md`。审查者按契约读 Diff，不凭个人口味挑刺。

- 什么叫出事了：<一句大白话的失败现象，不写术语>
- 人必须盯的地方：<只有机器审不出的：该不该做、高危区、会被整个代码库抄的架构模式>
- 跳过目录：<生成物、快照、第三方代码——一行一个>
- 挑刺上限：<本次最多报 N 条纯风格类发现，超出即止>
- 发现格式：文件名 + 行号 + 违反的契约条目 + 标签（严重 / 顺手改 / 存量）
- 无问题就写"无需修改"——空报告不等于漏审。

**契约维护**：连续多次审查都没用上某条目 → 过期，删掉或改写（契约过期本身就是 Standards 发现项）；同一条反复误报 → 改契约，不改审查者。
